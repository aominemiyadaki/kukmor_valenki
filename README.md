# Kukmor Valenki

Интернет-магазин настоящих Кукморских валенок

## Архитектура и Инструменты

- **Melos Monorepo**: Параллельная сборка, авто-линковка фич.
- **Dart Workspace**: Изоляция фич в `features/`.
- **Bloc 9 & AutoRoute 11**: Современный стэк стейт-менеджмента и навигации.
- **AI Token Optimization**: Предустановленный `.agentignore` для экономии контекста нейросетей.

## Команды

```bash
# Генерация кода
melos run build

# Запуск тестов
melos run test

# Анализ кода
melos run analyze
```
